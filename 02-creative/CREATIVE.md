## 1. Визуальная платформа

### 🎯 Ключевой визуальный образ

> **Растущий граф связей на тёмном фоне.**

Центральная метафора кампании: **одно первое сообщение** = один светящийся узел. От него расходятся линии к другим узлам, на каждой новой точке загорается «возможность» (янтарный огонёк). Граф растёт — и всё началось с одной точки.

```
                    🟧
                   ╱
       🟧 ──── 🟦 ──── 🟧
              ╱  │  ╲
            🟧   │   🟧 ── 🟩
                🟧
```

📁 Эталонный ИИ-сгенерированный муд-визуал: `assets/key_visual_network.png`

### 📐 Принципы композиции

| # | Принцип | Описание |
|:---:|:---|:---|
| 1 | **Тёмный фон — норма** | Кампания живёт в тёмной палитре. Метафора: «нетворкинг происходит в темноте, до того как вы узнали о результате» — и кинематографичная основа для контраста |
| 2 | **Свет = действие** | Светящиеся точки = конкретные люди и конкретные сообщения. Когда человек действует в TenChat, его узел загорается |
| 3 | **Линии — это связи** | Тонкие бирюзовые линии соединяют узлы. Чем больше связей, тем плотнее граф |
| 4 | **Реальные фото — для людей** | ИИ-визуалы для абстракций, муд-сцен и мокапов. Для живых людей — реальные фото, чтобы избежать «воскового» эффекта |

## 3. Типографическая система

| Уровень | Шрифт | Размер / вес | Где |
|:---|:---|:---|:---|
| **Display** (обложки) | Manrope ExtraBold | 88–120 pt | Слоган на обложке |
| **H1** (заголовки слайдов) | Manrope Bold | 48–64 pt | Заголовки секций |
| **H2** (подзаголовки) | Manrope SemiBold | 28–36 pt | Подзаголовки, CTA |
| **Body** | Inter Regular | 16–20 pt / 1.5 line-height | Основной текст |
| **Caption** | Inter Medium | 12–14 pt | Подписи, метаданные |
| **Numeric** | JetBrains Mono | 48–96 pt | Крупные цифры KPI |

## 5. Логотип кампании

### 🔤 Словесный знак

**«СВЯЗЬ»** — Manrope ExtraBold, кегль 96 pt, цвет `--text` (молочный) на тёмном фоне или `--bg` на светлом.

### 🎯 Графический знак

Одна точка бирюзового цвета с тремя расходящимися тонкими линиями к трём маленьким янтарным точкам. Минимализм — никаких сложных иконок.

```
                🟧
               ╱
   🟦 ──────── ── 🟧
               ╲
                🟧
```

### 🔗 Связка

Точка слева → слово «СВЯЗЬ» справа. Используется на обложках, в шапке лендинга, на OOH-носителях.

## 6. Tone of Voice

| ✅ Делаем | ❌ Не делаем |
|:---|:---|
| Документальный тон, как в кино | «Мотивационный спикер» |
| Короткие точные фразы | Длинные сложноподчинённые |
| Конкретные имена, цифры, места | «Многие», «некоторые», «огромный» |
| Глаголы действия: написал, позвонил, запустил | Абстрактные: развивайся, действуй, стремись |
| Реальные истории | Притчи и метафоры без фактуры |
| Тёмная палитра + свет = действие | Яркие улыбки и «успешный успех» |

## 8. Адаптивность и масштаб

Кампания построена так, что **любой формат — от билборда 6×3 до сторис 1080×1920 — сводится к одной композиции**: тёмный фон + один светящийся узел + короткий слоган.

```
   ┌──────────────────────────────────────────┐
   │                                          │
   │   📱 Stories 9:16    🖥 Баннер 1:1      │
   │       1080×1920        1080×1080         │
   │           │              │              │
   │           └──────┬───────┘              │
   │                  ▼                      │
   │          🟦 ─── 🟧 ─── 🟧              │
   │                  │                      │
   │           ┌──────┴───────┐              │
   │           ▼              ▼              │
   │   🏙 Билборд 6×3    📺 Видео 16:9       │
   │   (тёмный фон +     (те же принципы     │
   │    свет = действие)  композиции)         │
   │                                          │
   └──────────────────────────────────────────┘
```

Это позволяет:
- ✅ легко генерировать новые баннеры под разные офферы
- ✅ масштабировать визуальный язык на следующие кампании TenChat
- ✅ сохранять узнаваемость при любом размере носителя

## 9. UGC-движение «#Связь»

После запуска кампании запускается открытый call for stories: пользователи публикуют собственные истории с хештегом `#Связь` в ленте «Зевс».

### 🔄 Механика

| Этап | Что происходит |
|:---|:---|
| 1. Запуск | TenChat анонсирует call for stories через 3 брендированных поста в ленте «Зевс» |
| 2. Участие | Пользователи публикуют истории с хештегом `#Связь` |
| 3. Кураторство | Алгоритм «Зевс» бесплатно продвигает лучшие 10 постов в месяц |
| 4. Признание | Топ-3 истории в месяц получают фичеринг на главной TenChat и бонусные показы |

### 💎 Ценность для TenChat

- 📈 **Бесплатно генерирует контент** — 1400 историй за 8 недель
- 🔁 **Удерживает аудиторию** после рекламной волны
- 🌱 **Превращает кампанию в долгоживущий бренд-движок**
