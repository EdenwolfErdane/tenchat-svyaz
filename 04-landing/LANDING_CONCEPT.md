## 🎯 1. Цель лендинга

Превратить зрителя ролика и баннера в **зарегистрированного пользователя TenChat**.

### 📊 Воронка

```
   показ → визит → регистрация → первое действие
                        │
                        ▼
                написать сообщение
                опубликовать пост
                свайп в Бизнес.Тиндере
```

## 🏗 2. Структура страницы

### 🎬 Секция 1 — HERO (высота 100vh)

**Фоновое видео**: `scene_zero_point.png` на мобильных, видео-анимация графа на десктопе.

**Заголовок** (крупно, по центру):

Один контакт —
целая траектория.

**Подзаголовок**:

### 📖 Секция 2 — ИСТОРИЯ ДИНЫ (полноэкранный скролл-секвенс)

**Механика**: при скролле пользователь видит «ленту времени» — 6 ключевых моментов истории. Каждый момент — отдельный кадр с текстом.

| Шаг | Заголовок | Текст | Визуал |
|:---:|:---|:---|:---|
| 1 | **Точка ноль** | «Дина, 26 лет. 200 откликов. 0 ответов.» | `scene_zero_point.png` |
| 2 | **Один комментарий** | «4 строки под постом Тимура, ex-Yandex PM.» | скриншот поста |
| 3 | **Ответ через 2 часа** | «„Можешь созвониться завтра в 14:00?"» | скриншот уведомления |
| 4 | **Первая встреча** | «Коворкинг, два ноутбука, чашка кофе.» | `scene_meeting.png` |
| 5 | **Команда** | «Месяц 4. 4 человека. Первый клиент.» | `scene_team.png` |
| 6 | **Агентство** | «Месяц 6. „Сигнал". Выручка 1,8 млн ₽.» | `hero_dina.png` |

**Внизу секции**:
> «Я не была талантливее других. Я просто написала 4 строки.» — Дина

## ⚙️ 3. Технические требования

| Параметр | Значение |
|:---|:---|
| 🖥 Десктоп | 1920×1080+, оптимизация под 1440 |
| 📱 Мобильные | 375×667 (iPhone SE) → 430×932 (iPhone 14 Pro Max) |
| ⏱ Время загрузки (LCP) | < 2,5 сек |
| 🛠 Технологии | HTML + vanilla JS (калькулятор, свайпы), CSS Grid + Flexbox |
| ✍️ Шрифты | Manrope + Inter с Google Fonts |
| 📊 Аналитика | Yandex Metrica + собственная через TenChat analytics |
| 🎯 Цели в метрике | (1) клик по любой CTA, (2) доход до конца истории Дины, (3) использование калькулятора, (4) завершение регистрации |
