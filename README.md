## 🎯 О кампании

**СВЯЗЬ** — победная креативная кампания для **TenChat**, крупнейшей российской деловой социальной сети. Кампания делает видимым то, что обычно невидимо: как одно деловое знакомство превращается в реальную возможность — нового клиента, работу, проект, партнёрство или собственное дело.

| Параметр | Значение |
|:---|:---|
| **Бренд** | TenChat |
| **Слоган** | Один контакт — целая траектория |
| **Подслоган** | TenChat. Связь, которая становится делом |
| **Срок кампании** | 8 недель |
| **Бюджет** | 6 500 000 ₽ |
| **Целевая аудитория** | 22–35 лет, профессионалы в IT/маркетинг/B2B |
| **Стиль** | Эмоциональное кино, документальный тон |

### Почему это работает

- 🔍 **Делает ценность нетворкинга видимой** — показывает траекторию, а не абстрактное «знакомьтесь»
- 🛠 **Использует реальные механик TenChat** — лента «Зевс», прямые сообщения, «Бизнес.Тиндер»
- 🎨 **Создаёт узнаваемый визуальный код** — растущий граф связей как фирменный знак
- 🔄 **Запускает UGC-цикл** — хештег `#Связь` генерирует контент для ленты

## 🎬 Hero-история Дины

```
200 откликов. 0 ответов.

→ 4 строки под постом Тимура, ex-Yandex PM
→ Ответ через 2 часа в личку
→ День 14: первый коммит
→ Месяц 2: первые клиенты
→ Месяц 6: агентство «Сигнал», 1,8 млн ₽/мес, 7 человек в команде
```

> «Я не была талантливее других.  
> Я просто написала 4 строки под постом человека, которого не знала.  
> Это всё, что меня отделяло от 200 откликов на hh без ответа.»  
> — **Дина**, CTO агентства «Сигнал»

## 🎨 Креативная система

### Цветовая палитра

| Роль | HEX | Использование |
|:---|:---|:---|
| Фон | `#0A1628` | Глубокий ночной синий, базовый фон |
| Текст | `#F5F5F0` | Молочный, основной текст |
| Сигнал | `#00D4FF` | Бирюзовый, CTA и узлы графа |
| Встреча | `#FF9E3D` | Янтарный, точки контакта |
| Успех | `#4ADE80` | Зелёный, позитивные метрики |

### Типографика

| Назначение | Шрифт |
|:---|:---|
| Заголовки | **Manrope** (geometric sans, современный) |
| Body-текст | **Inter** (отличная читаемость) |
| Цифры / код | **JetBrains Mono** (IT-контекст) |

### Ключевой визуал

> Растущий граф связей на тёмном фоне:  
> 🟦 одна бирюзовая точка → 🟧 янтарные «возможности» на каждом новом узле  
> Граф растёт во все стороны — но всё началось с одной точки.
